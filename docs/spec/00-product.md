# 00 — Product

## Goal

Free, MIT-licensed Docker alternative for Windows 11+: one installer that provisions a private Docker Engine in WSL2 and a GUI that covers the **full Docker CLI surface** with visual editors. No dependency on Docker Desktop.

## Fixed decisions

| Topic | Decision |
|---|---|
| Name / owner | Nautix — patterna.dev |
| License | MIT (`LICENSE` at root, SPDX header not required in files) |
| Platform | Windows 11 (build 22000+) x64; arm64 is a later milestone |
| UI | WPF on .NET 10 |
| UI pattern | MVU (unidirectional, immutable state) |
| Languages | English (default), Spanish. Culture switch at runtime without restart |
| Themes | Dark, Light, System. Switch at runtime |
| Engine | Docker Engine (moby) installed in WSL2 distro `nautix-engine` |
| Engine connection | **Managed**: Nautix-owned named pipe `\\.\pipe\nautix_engine`, relayed to the engine socket. No TCP |
| Docker API client | `Docker.DotNet` behind `IContainerEngine`; Docker CLI for Compose/buildx/bake/login/context |
| Architecture | Hexagonal modulith + Mediator |

## In scope

1. Installer/wizard that provisions WSL2 feature, imports `nautix-engine`, installs docker CLI/compose/buildx for Windows, creates and selects docker context `nautix`.
2. Dashboard and CRUD for containers, images, volumes, networks, builds, registries, swarm, contexts, plugins, system.
3. Visual **network graph** (containers/networks/volumes, live from the engine).
4. Visual **Compose editor** (graph ⇄ form ⇄ YAML, all in sync, comments preserved).
5. Visual **Dockerfile editor** (instruction blocks ⇄ text, multi-stage graph, lint).
6. Integrated terminal (PowerShell/cmd/`docker` passthrough, container exec/attach).
7. Coverage of all 53 commands in `docker --help` (see `05-commands.md`).
8. Tray icon, notifications, auto-start option, signed updates.

## Non-goals (do not build)

- Kubernetes, Docker Desktop extensions, Windows containers, Linux VM other than WSL2.
- Cloud sync, accounts, multi-user server mode, remote engines (context list is shown, editing allowed, but no remote provisioning).
- Message brokers, Redis, any external cache.
- Telemetry on by default (opt-in only, no PII).

## Personas (for UX decisions)

- **Dev from WinForms/.NET background**: wants to click rather than type; needs confidence about what command is being run → every action has a "Show command" affordance that displays the equivalent `docker` CLI line (generated by the same `CommandPreview` service used for execution logging).
- **Corporate laptop user**: may lack admin rights. Installer has a **client-only mode** (skip engine provisioning; connect to existing context).

## Success criteria for v1.0

- Fresh Windows 11 → working `docker run hello-world` from both Nautix and any terminal in < 10 min on broadband.
- 100% of commands in `05-commands.md` marked `Done` (visual or terminal).
- Compose round-trip corpus (≥ 200 real-world files) preserved byte-for-byte for no-op edits.
- Graph editor: 300 nodes at ≥ 30 fps on a mid-range laptop.
- Idle memory < 250 MB for the GUI process (excluding the engine VM).
